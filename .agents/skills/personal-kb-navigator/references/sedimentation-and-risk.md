# 沉淀规则、整理原则与风险边界（参考）

> 本文件是 `SKILL.md` §6/§8/§9 的展开：**三条铁律、归属判定、整理原则、风险边界、人格校准清单、工具分工**。
> 内容为通用规则；示例中的库名与路径以该库 `<KB_ROOT>\AGENTS.md` 的实际结构为准。

## 1. 三条沉淀铁律

### 铁律 1：按主题分子文件夹，不按来源分

决定素材放进哪个文件夹的，是它**讲什么主题**，而不是它**从哪里来**。

> 反模式：建立「来自公众号」「来自某个记录工具」这类来源目录，导致同一主题的证据散落多处。

### 铁律 2：每条素材独立成 md，末尾加基础标签

一条素材对应一个独立文件；在末尾打上基础标签。

### 铁律 3：每次入库都必须标注资产归属

每条素材都要回答「这是谁的、从哪来、将来在哪用」。

## 2. 归属标签模板（二选一）

```
🧭 归属：自有产出 / 与我相关
📌 来源：……
🎯 应用：……
```

```
🧭 归属：外部学习 / 他人资料
📌 来源：……
🎯 应用：……
```

### 归属判定

| 归属 | 判据 |
|---|---|
| **自有产出** | 我写的 / 我说的 / 我做过的；我的产品、客户、学员、团队、朋友圈、公众号、咨询、复盘、聊天记录 |
| **外部学习** | 书、课程、文章、对标账号、公开案例、行业资料、他人方法论 |

- **混合材料只选一个主归属**。
- 仅当材料**低置信度**、可能影响关键分类、或会改变后续调用方式时，才向用户确认。

> **为什么归属是基石？** 它决定了后续能否对外使用、是否需要脱敏、是否要标注历史风险。缺失归属的素材无法安全调用——你不知道能不能引用它，也不知道它的时效性。因此「收藏即入库」不成立，必须回答三问。

## 3. 整理原则

| 原则 | 内容 |
|---|---|
| 原话与整理稿分开 | 对话原话与 AI 整理结果必须分开保存，**不得用整理稿覆盖用户原话** |
| 原文永不覆盖 | 整理时不覆盖外部记录原文，保留可回源的一层 |
| 回源层 / 前台可调用区分离 | 核心库放可直接调用的资产；回源/施工区只承担施工与回源 |
| 最小工作流 | 优先验证「不增加使用者负担」；数据流跑通前不扩张大库与卡片体系 |
| 按需提炼 | 原文可保留，但**高频调用**时才提炼成可读、可复用的卡片 |
| 阶段性产物落位 | 处理工作台不长期堆在根目录 / 核心库前台，统一进回源/施工区的处理工作台 |
| 根目录极简 | 主题库若干 + 一个回源/施工区 + 说明文件 |

> **AI 整理时必须遵守的九条规则**（先存原话 / 不覆盖外部原文 / 按用途分类 / 只建明确应用的卡 / AI 稿与原话分开 / 旧产品标历史风险 / 人物客户先脱敏 / 更新入口与总控 / 新资产让调用更方便）**内联于 `SKILL.md` §7**——执行时常驻，此处不重复列举，避免两份清单漂移。

## 4. 风险边界

### 4.1 历史资料

旧价格、旧权益、旧发售节奏**一律标注历史资料或过时风险**，避免被当作当前有效口径。

### 4.2 脱敏

涉及**客户、私教、聊天、人名、收入、未公开策略**的内容，对外使用前要脱敏。

### 4.3 判断边界（反向护栏示例）

- 《AI 可以辅助整理，但不能替我体验和判断》
- 《可能性清单不等于现实承诺》
- 《个人健康记录不等于医疗建议》

### 4.4 身份与称呼

资料中出现的作者本名、别名或缩写，均视为知识库所有者本人；以哪个称呼为主，以该库 `<KB_ROOT>\AGENTS.md` 的记载为准。

## 5. 写作前人格校准清单（7 项）

代写、改写或整理**公开内容**前，逐项检查：

1. 要不要出现身份锚点？
2. 有没有真实经历作为证据？
3. 有没有强判断，而非泛泛建议？
4. 有没有不该夸大 / 不该承诺的地方？
5. 更适合公众号、朋友圈、销售页还是咨询交付？
6. AI 提供的是**候选**，还是**已被我确认并真正代表我的判断**？
7. 有没有用流畅的 AI 表达替代我自己的体验、证据和语言？

> **为什么这份清单必要？** 它把「AI 代写」的边界显式化：AI 可以组织语言，但不能替代本人的体验、证据与判断。第 6、7 项是防止「AI 生成的流畅表达被误当成本人观点」的最后一道闸。

## 6. 外部记录工具与本地库的临时分工

| 载体 | 角色 |
|---|---|
| 外部记录工具（如笔记 / 大纲类应用） | 使用者熟悉的阅读、思考和持续记录空间 |
| 本地知识库 | AI 的处理、检索、去重、风险校验和资产调用空间 |
| 对话收件箱 | 保存当前任务中输入的原话 |
| 原文备份 | 用于回源，不作日常阅读入口 |

> 这是**临时分工**，不代表已决定本地或外部工具谁是永久唯一主库。
