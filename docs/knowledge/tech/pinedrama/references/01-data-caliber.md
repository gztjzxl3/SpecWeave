# PineDrama 调研数据口径与冲突说明

短剧出海赛道存在多套数据机构（Sensor Tower、DataEye、Owl &Co.、Omdia、MPA 等），各机构统计范围、是否覆盖第三方安卓市场、收入端是流水还是内购均不同。本页集中登记本知识束引用数字的口径，并对冲突口径做并列处理。

冲突原因分析：①统计对象不同（仅内购收入 vs 含广告收入；仅美国 vs 全球/海外）；②机构模型不同（Sensor Tower 以商店内购为主，广告收入估算差异大）；③发言者立场不同（从业者倾向给出更高天花板）。引用时必须连同机构名与范围一起引用。

### 2.2 全球短剧下载与收入（2026Q1）

- 下载量超 8.5 亿次，同比约 +140%；同期内购收入约 7.5 亿美元，同比约 +20%——Sensor Tower 口径（S-06 转引）。
- 注意"内购收入"不含广告收入，因此该组数字刻画的是 IAP 模式的增长减速，而非全行业（含 IAA）总收入减速。

### 2.3 国别下载与收入分布（DataEye，2026-08）

- 下载 Top3：印度 13.8%、印尼 12.9%、巴西 10.4%，合计近四成全球下载。
- 收入 Top5：美/日/韩/英/澳合计约一半全球流水，美国约占近三成。
- 两组分布为同一机构同一月份口径，可直接对照（下载高地与收入高地错位）。

### 2.5 竞品单月内购收入（2026-07，S-17 汇编，`[SINGLE-SOURCE]`）

- DramaBox（点众科技）：约 3560 万美元，当月首次超过 ReelShort。
- ReelShort（枫叶互动，中文在线参股背景）：约 2850 万美元。
- MPA 预测 ReelShort 2026 全年 10.5 亿美元（约 +34%）。
- 以上为第三方汇编口径，与 Sensor Tower 月度榜单可能存在统计差异。

### 2.6 免费模式时长份额

- Owl &Co.：免费广告短剧应用占用全球短剧用户总时长比例，2025Q1 为 15%，2026Q2 为 83%（S-06/S-08 转引，原始报告未取得）。
- 该"时长"为用户观看时长口径，非下载量或收入口径，不可与下载份额直接比较。

## 4 引用检查清单

写作者引用本束任何数字前，请确认：

1. 是否保留了机构名（Sensor Tower / DataEye / Omdia …）？
2. 是否保留了时间（月份/季度/预测年份）？
3. 指标是下载、DAU、内购收入还是含广告收入？
4. 该数字是否标注了 `[SINGLE-SOURCE]`？若是，不得作为结论唯一锚点。
5. 市场规模类数字是否连同地理范围（美国/全球/海外）一起引用？
