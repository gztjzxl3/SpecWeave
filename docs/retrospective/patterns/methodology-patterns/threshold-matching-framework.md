# 三维门槛匹配决策框架（Threshold-Matching Framework）

> 面对 ≥3 个可选变现或副业方案时，先用「资金 × 技能 × 时间」三维禀赋过滤机会集，再用中位收入与平台政策依赖做二次校验，最后以书面化迭代/退出条件锁定资源配置——决策预期锚定中位分布，而非头部幸存者案例。

## 一句话定义

个人/小团队的机会选型不是"挑最热的方向"，而是一道资源配置约束题：先以自身三维禀赋（资金、可迁移技能、每周可投入时间）为硬门槛过滤方案矩阵，再用中位收入对时间机会成本做经济性校验、以平台政策原文对单点依赖做风险校验，把感性冲动转化为可判定、可迭代、可退出的结构化决策。

## 触发场景

**适用于**：
- 个人/小团队面对 ≥3 个可选变现或副业方案，无法决定优先级
- 拥有某种禀赋（资金/技能/时间），寻找与之匹配的机会方向
- 曾用"热门案例"做决策预期后遭遇现实落差，需要重新理性选型

**不适用于**：
- 组织级预算决策：多干系人、组合化 ROI 与战略协同权重主导，个人禀赋三维过滤不足以刻画约束集
- 信息完全缺失的新领域首轮选型：无中位收入数据可查时经济性校验（步骤 3）失效，应先做小成本探索性调研再套用本模式
- 已有明确唯一解的执行任务：方案间无需比较时，过滤流程是纯开销

## 核心步骤（6 步）

1. **盘点三维禀赋**：资金分四档——零成本（<1000 元）/低（<1 万）/中（1–10 万）/高（>10 万）；可迁移技能分四类——无专项/内容型（写作/拍摄/审美）/技术型（编程/自动化）/行业专家型（垂直领域 know-how）；每周可投入时间分三档——<10h/10–20h/>20h。档位判定写下来，不凭感觉。
2. **一维过滤**：按三维禀赋过滤方案矩阵，排除任一维度不达标的方案（例：零资金 + 每周 <10h → 排除硬件、深度 SaaS；保留提示词售卖、标注众包、轻内容）。
3. **中位收入校验**：用各方案的中位/典型收入（非头部案例）核算 6 个月现金流，淘汰"中位收入 < 时间机会成本"的方案。
4. **平台依赖与合规校验**：核对目标平台政策原文（标识义务/分成规则/封号条款），标注平台依赖度（高/中/低），淘汰"高依赖 + 无自有阵地"组合（对冲手法见 [平台依赖风险对冲](platform-dependency-hedging.md)）。
5. **设定迭代与退出条件**：单方案验证期 3 个月，未达到该方案中位收入的 50% 则切换；同期并行方案 ≤2 个。
6. **B/C 结构配比**：技能型优先以 B 端 retainer 构建收入底盘（3–5 家客户），C 端内容/产品作为获客漏斗与杠杆。

## 检验标准（怎么知道做对了）

- 三维禀赋以可判定的档位留痕（资金档位/技能类型/每周小时数），每个候选方案在每一维上均有明确的"达标/不达标"结论，而非凭印象排序
- 收入预期一律采用中位/典型值且能指出来源（调研事实编号或行业统计），不存在以头部案例直接推算的预期
- 每个存活方案均完成平台政策原文核对并标注依赖度（高/中/低），"高依赖 + 无自有阵地"组合数量为零
- 存在书面化的迭代与退出条件（验证期时长、切换阈值、并行上限），且实际并行方案数未超上限
- B/C 结构配比有明确指标（B 端底盘客户数、C 端漏斗角色），而非只规划 C 端流量

## 反模式（均来自实际教训）

1. **头部案例锚定**：用幸存者案例（如单人 MRR 十万美元）做收入预期，忽略中位分布——预期系统性高估，验证期判定随之失真。
2. **方案散弹**：同时启动 3 个以上方案，任一方案均未达验证阈值——资源摊薄后所有方案都拿不到有效验证信号。
3. **技能错配追热点**：零技术背景强做 SaaS、零内容能力强做自媒体——禀赋一维过滤被跳过，选型退化为热点跟随。
4. **忽视政策原文**：直接搬运 AI 内容不做标识、押注单一平台分成规则——合规与依赖风险在启动后才暴露，切换成本远高于选型成本。
5. **人力型长期化**：把零边际成本可替代的人力型任务（标注/基础接单）当作长期主业而非过渡现金流——模式本身会被自动化侵蚀，长期持有即负资产。

## 跨场景迁移示例

- **场景 A（自由职业方向选择）✅ 通过**：设计师在"平台接单（Fiverr/猪八戒）/直客 retainer/数字商品（模板售卖）"间选型——三维禀赋过滤与中位收入校验完全适用，平台依赖校验同样成立（平台抽成与封号风险 vs 自有客户关系）。
- **场景 B（新技术参与决策）✅ 通过**：个人面对 Web3/新硬件等新兴领域的参与方式选型（炒币 vs 建站 vs 内容科普）——三维禀赋 + 中位收入 + 政策依赖三层校验可直接迁移。
